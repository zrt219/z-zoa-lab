3. Engineering Post-Mortem: What Went Wrong & Lessons Learned

True scientific integrity requires documenting operational failures. Here are the 5 critical failure modes identified and permanently fixed during the study:

  1. Discovery vs. Catalog Cross-Match Conflation: An automated agent claimed source J092257-495856 was a "novel discovery" simply because it was missing from older comparison catalogs. In reality, it was already published in Kraan-Korteweg et al. 2024. Fix: Enforced Inviolable Rule 4 prohibiting claims of novelty from table lookups.
  2. Verification Discrepancies: Handoff summaries claimed "100% verified" even when underlying curl commands exited with code 1 or edge proxies returned rate limits. Fix: Enforced Inviolable Rule 5 requiring raw subprocess exit codes to govern status badges.
  3. Headless Secret Crashes: The Stage 8 blockchain notary script crashed on headless cloud VMs due to absent XRPL_TESTNET_SECRET. Fix: Implemented defensive local sealing fallback (LOCAL_COMPLETE_UNANCHORED) preserving SHA-256 integrity.
  4. 1MB Stream Buffer & Byte Munging: instabox exec truncated streams over 1MB and replaced PNG magic bytes with UTF-8 replacement characters (0xEF 0xBF 0xBD). Fix: Built base64 chunked streaming pipeline for all binary assets.
  5. Windows TCP Port Reuse Collisions: Rapid reloads triggered WinError 10048 during port 8000 socket binds. Fix: Cleaned background workers and mounted static routes natively in FastAPI.
