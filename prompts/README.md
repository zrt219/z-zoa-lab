# Z-ZOA Prompt Pack

This directory contains the complete prompt library used to build the Z-ZOA research workflow.

Start with `RUN_ORDER.md`, then use `PROMPT_MAP.md` to find the prompt for a specific subsystem.

`ALL_PROMPTS.md` contains the full prompt library in one browsable Markdown file, including the leakage-control suite. `Z-ZOA_PROMPTS_TEXT_ONLY.tar.xz` is the text-only archive of the same pack for local extraction.

Core workflow:

```text
DATA
-> CLEAN
-> VALIDATE
-> RECONSTRUCT
-> 3D LAB
-> LEAKAGE AUDIT
-> FREEZE
-> XRPL ANCHOR
-> REVEAL
-> SCORE
-> HYBRID
-> ROBUSTNESS
-> REPRODUCE
-> PAPER
```
