# /goal — Visualize the validated prediction vs hybrid reconstruction in the 3D Lab

Only run this after `13_REVEAL_AND_SCORE_MEERKAT.md` and `14_HYBRID_RECONSTRUCTION.md` are complete.

Add a post-reveal comparison workspace that consumes the scientific pipeline's frozen comparison artifacts.

## Required views

Allow the researcher to inspect:
- prediction reconstruction (without selected MeerKAT holdout);
- revealed H I validation catalogue;
- hybrid reconstruction;
- backend-computed Delta density;
- backend-computed Delta velocity;
- backend-computed uncertainty reduction;
- regions where classification/topology changes if the scientific pipeline produced such an artifact.

## Rules

- Every delta field must be generated by the scientific backend and have parent run IDs.
- 3D Lab may change opacity, clipping, camera, and visible layer selection only.
- Viewer interactions must never change the paper's stored validation score.
- Clearly distinguish `PREDICTION`, `OBSERVED HOLDOUT`, `HYBRID`, and `DELTA` layers.

## Useful comparison interactions

Provide synchronized slices/selection and a selected-voxel inspector showing before/after values and uncertainties.

## Export

Allow export of camera/state metadata for reproducing a supplementary view, but do not treat screenshots as paper data.

## Completion gate

Demonstrate with synthetic before/after artifacts first, then enable for authorized real validation/hybrid runs.
