# Leakage test 02 — Exact identifiers and alias duplicate scan

Compare candidate training catalogues with the configured holdout for exact or normalized identifier overlap.

Check:
- survey IDs;
- object names;
- canonical IDs;
- known aliases from notes/crossmatch columns;
- duplicate rows with identical coordinates/velocities but different labels.

Create an exclusion candidate list with evidence. Do not infer that an ID mismatch means independence; later positional tests must still run.
